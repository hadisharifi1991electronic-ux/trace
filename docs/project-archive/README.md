# Project archive

A backup of the planning and working notes behind Trace, kept here so the
project can carry on without the Claude project it was built in. Snapshot
taken 2026-11-26 (after 0.109.1).

- `design-doc/design-doc.md`: the original design doc (goals, users, features,
  architecture, phased plan, decisions). Two embedded diagrams were not
  exportable and appear as placeholders.
- `memory/`: the project memory. `MEMORY.md` is the index (current state,
  queue, standing rules, how releases and installs work); the other files are
  older release history, the backlog, and working preferences.
- `threads/thread-index.md`: every feature thread, its dates and state.
- `release-files/`: reports and screenshots per version (`reports/<version>/`),
  via sizing results, ADI port models (`adi/`), app screenshots (`screens/`),
  logo options and the RF cross-section picture (`misc/`), plus older copies of
  the README and CHANGELOG (the current ones are at the repo root).

Not included on purpose: Hadi's own Altium SDR card design files and anything
showing them, third-party sample boards, and the Windows executables (those are
on the `dist` branch).
